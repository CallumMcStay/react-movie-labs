# react-movie-labs

This app allows you to view movies.
You can see 3 different arrays of movies
      A discover page that lets you see current popular movies
      An Upcoming page that lets you see upcoming movies that are releasing soon
      A Top Rated page that lets you see the best rated movies at the moment!

You can also add movies from these lists to either Favourites or a Watch List Page to watch later or both!

It uses the TMDB website to get information on all the Movies using endpoints made by them.
